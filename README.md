# Triathlon iPhone V5 – GitHub Pages

Alle fünf Dateien in das Stammverzeichnis deines bestehenden öffentlichen GitHub-Repositories `triathlon-app` hochladen (alte gleichnamige Dateien ersetzen). GitHub Pages bleibt auf Branch `main`, Verzeichnis `/ (root)`. Danach Safari unter https://paulahetf.github.io/triathlon-app/ öffnen und ggf. Seite neu laden.

Enthalten: V5-Trainingsplan, Kalender, Häkchen, Tagesverschiebung, FTP-basierte Zonen als Orientierung, Fortschritt, CSV-Import/-Export, Offline-Cache. Die FTP-Einstellung ändert **nicht** automatisch bereits im CSV-Plan festgeschriebene Wattzahlen. Keine automatische Strava-Synchronisierung.

Achtung: Plan, Häkchen und Verschiebungen sind nur lokal im Browser gespeichert; bei Löschen der Websitedaten können sie verloren gehen. Regelmäßig CSV exportieren. CSV-Plan ist auf öffentlichen GitHub Pages öffentlich sichtbar.
